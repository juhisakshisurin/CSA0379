# Data Structures with C

## About
This repository contains C programs implemented as part of the Data Structures course. It covers fundamental data structures, algorithms, and problem-solving techniques through practical programming exercises.

## Topics Covered
- **Arrays:** Element searching, array rotation, and manipulation
- **Searching:** Linear Search and Binary Search
- **Recursion:** Factorial and Fibonacci series
- **Linked Lists:** Singly Linked List implementation
- **Structures:** Student record management using arrays of structures
- **Pointers:** Pointer arithmetic and array operations
- **Matrices:** Matrix multiplication and related operations

## Technologies Used
- **Programming Language:** C
- **Compiler:** GCC or any standard C compiler
- **Tools:** Visual Studio Code, Code::Blocks, or equivalent C development environments

## How to Run
1. Clone this repository:
   ```bash
   git clone https://github.com/juhisakshisurin/CSA0379.git
   ```
2. Navigate to the repository folder:
   ```bash
   cd CSA0379
   ```
3. Compile a C program:
   ```bash
   gcc "Binary Search Program.c" -o binary_search
   ```
4. Run the executable:
   ```bash
   ./binary_search
   ```
   On Windows, use:
   ```bash
   binary_search.exe
   ```

Replace the filename in the compilation command with the program you want to execute.

## Purpose
The purpose of this repository is to practise C programming, understand core data structures and algorithms, and develop logical thinking and problem-solving skills.

## Repository Contents
Each source file contains an individual C program demonstrating a specific data structure, algorithm, or programming concept.
